# FlowVLA project page

Static project page for **FlowVLA: Learning Flow-Aware Physical Completion for Quantitative Robotic Pouring**.

Live site: <https://rah-xephon.github.io/FlowVLA-page/>

![FlowVLA project page preview](assets/preview/flowvla-home.png)

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Media

- The main project video is a branded edit of the author-provided BGM version.
- The four smaller videos are the selected 100 g, 200 g, 300 g, and generalization groups.
- Videos use H.264 for browser compatibility and are loaded lazily below the fold.
